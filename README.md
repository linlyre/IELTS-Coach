# 雅思写作提分教练

雅思写作提分教练是一款面向中文雅思备考学生的 Writing Task 2 私人教练产品。它不是泛用 AI 作文检查器，而是帮助你持续管理作文、理解句子级问题、完成反思和复训，并长期追踪写作成长。

## 你可以用它做什么

- 提交 IELTS Writing Task 2 英文作文，获得结构化教练报告。
- 查看非官方诊断分、四项评分维度、最大短板和优先改进方向。
- 在提升预览中查看标红句、标黄句、AI 解答、AI 改进和四维具体建议。
- 保存反思笔记，把一次反馈变成下一次写作前可复盘的训练记录。
- 完成专项训练任务，围绕最大短板进行复训。
- 在作文档案中管理历史作文，查看报告、训练进度和反思状态。
- 在成长看板中追踪诊断分趋势、四维均值、累计作文数和当前短板。

## 适合谁

- 正在备考 IELTS Writing Task 2 的中文学习者。
- 希望从“看一次批改”转向“长期提分训练”的学生。
- 想知道自己反复犯哪些句子、结构、词汇或语法问题的人。
- 需要管理多篇作文和复盘记录的自学考生。

## 使用流程

1. 注册并登录账号。
2. 完成学习档案设置，包括目标分、当前水平和备考目标。
3. 在“开始练习”中提交 Task 2 题目和英文作文。
4. 查看写作教练报告，理解本次最大短板和优先改进项。
5. 进入提升预览，逐句查看问题解释和改进示例。
6. 保存反思笔记，完成训练任务。
7. 在作文档案和成长看板中持续追踪进步。

## 关于诊断分

产品中的诊断分和建议仅用于学习训练，不代表官方 IELTS 分数，也不能替代官方考试评分。你应把它看作写作训练中的复盘参考，用来定位问题、安排练习和观察长期变化。

## 数据与隐私

为了生成报告和追踪成长，产品会保存你提交的作文、题目、教练报告、反思笔记和训练状态。你的作文内容会被用于生成个人训练反馈，不会在产品中公开展示给其他用户。

你可以删除作文；删除后，与该作文关联的报告、薄弱点、提升预览、反思和训练任务也会一并删除。

## 目前聚焦范围

当前版本专注于 IELTS Writing Task 2：

- 不提供 Writing Task 1。
- 不提供听力、阅读、口语模块。
- 不提供官方分数预测。
- 不提供支付、人工批改或老师入驻功能。

## 重要提醒

请不要在作文中填写敏感信息。提交内容应仅包含与雅思写作训练相关的题目和作文正文。
